# Sovereign Operator Record

Authority record for the Sovereign Workspace programme: operator directives,
adjudications, and the append-only `OPERATOR-INSTRUCTIONS.log` (ENTRY 001–038).

This repository is the citation source referenced by the audit documents in
[`sovereign-workspace-release`](https://github.com/darksciencedivision-ctrl/sovereign-workspace-release).
It is a historical record — entries are append-only and are not edited after the fact.

## Contents

- `OPERATOR-INSTRUCTIONS.log` — verbatim operator instructions with their expanded
  authorization tokens, in chronological order.
- Supporting directives and adjudication records cited by the release audit trail.
